# Projet Villa DUPONT – Terminale Bac Pro TEB-AA

Site du projet fil rouge commun aux unités U21, U22 et U23.

- `index.html` : principe, pôles, planning, échanges, pièces du PC
- `dossier.html` : dossier client, documents, conventions, registre
- `u21.html`, `u22.html`, `u23.html` : séances par pôle
- `ressources/` : fichiers à télécharger (trames, fiches méthode, données d'entrée)

Publication : Settings → Pages → branche `main`, dossier `/ (root)`.
Modification : les pages sont générées par `build.py` à partir des données en tête du fichier.
