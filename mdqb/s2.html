S2Préparer la maquette : fond de plan et types de parois

« Comment préparer une maquette pour que le second œuvre s'y modélise juste du premier coup ? »

Le tableau des types est validé. Vous préparez la maquette avant de modéliser : fond de plan calé, types créés, paramètre de lot.

Déroulé

  1. 15 min

    Lancement

    Rappel Revit : enregistrer sous votre nom, organisation des vues, sauvegardes.

  2. 45 min

    A · Niveaux et fond de plan

    • Enregistrez la maquette sous TEBAA_MDQB_NOM_Prenom.rvt.
    • Contrôlez les niveaux et la hauteur sous plafond dans une coupe.
    • Liez le DWG du RDC : unités en mètres, couche visible seulement, positionnement manuel.
    • Calez le DWG sur deux poteaux, puis épinglez-le.
    Méthode · Lier et caler un DWG
    • Insérer › Lier CAO : couleurs noir et blanc, unités mètres, positionnement manuel.
    • Déplacer le lien en accrochant un point connu (axe de poteau).
    • Vérifier un deuxième point pour contrôler l'orientation.
    • Modifier › Épingler pour éviter tout déplacement.
  3. 90 min

    B · Types de murs, sols et plafonds

    • Dupliquez un type de mur de base pour chaque ligne DBL- et CLO- de votre tableau.
    • Éditez la structure : couches, matériaux, épaisseurs, fonction de chaque couche.
    • Faites de même pour les types de sol (SOL-) et de plafond (FP-).
    • Vérifiez que l'épaisseur totale de chaque type correspond au tableau.
    Méthode · Créer un type de mur composé
    • Sélectionner un mur › Modifier le type › Dupliquer › nommer avec le code du tableau.
    • Structure › Modifier : ajouter les couches, affecter le matériau et l'épaisseur.
    • Placer l'ossature en noyau, les plaques en finition.
    • Contrôler l'épaisseur totale affichée.
  4. 30 min

    C · Paramètre « Lot CCTP »

    • Créez le paramètre partagé Lot CCTP (texte, par type) pour les murs, sols, plafonds et portes.
    • Renseignez-le pour chaque type créé (07, 06, 03).

On vous donne

  • Maquette clos-couvert (.rvt)
  • DWG : RDC 1/50 et coupe A-A

Livrables

  • Maquette avec DWG calé, types créés, paramètre renseigné
